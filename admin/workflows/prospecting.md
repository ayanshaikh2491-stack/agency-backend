# Prospecting Workflow

## Overview
- **Purpose**: Identify and qualify potential leads for TAGS Agency.
- **Agents**: CEO, SBA
- **Trigger**: Heartbeat event (every 120s)
- **Checkpoint**: None (autonomous)
- **Push Right**: Research, outreach, and content generation
- **Brief**: Summary of leads found, content created, and website updates

## Tasks
1. **Identify Niches**:
   - **Agent**: CEO
   - **Task**: Research starving crowd niches for local B2B service businesses.
   - **Output**: List of niches with potential leads.

2. **Research Leads**:
   - **Agent**: SBA
   - **Task**: Find businesses in the identified niches.
   - **Output**: List of potential leads with contact details.

3. **Generate Content**:
   - **Agent**: Content
   - **Task**: Create content for the identified niches.
   - **Output**: Content pieces for outreach.

4. **Update Website**:
   - **Agent**: Website
   - **Task**: Add content to the agency website.
   - **Output**: Updated website with new content.

## Output
- **Leads Found**: List of potential clients with contact details.
- **Content Created**: Content pieces for outreach.
- **Website Updated**: Agency website with new content.
