# Delivery Workflow

## Overview
- **Purpose**: Deliver client services and set up client websites.
- **Agents**: Website, Content, SEO
- **Trigger**: Lead conversion
- **Checkpoint**: CEO approval for external actions
- **Push Right**: Website setup, content creation, and SEO optimization
- **Brief**: Client onboarding status and next steps

## Tasks
1. **Set Up Client Website**:
   - **Agent**: Website
   - **Task**: Create a client website based on lead details.
   - **Output**: Client website setup.

2. **Create Content**:
   - **Agent**: Content
   - **Task**: Generate content for the client website.
   - **Output**: Content pieces for the client website.

3. **Optimize SEO**:
   - **Agent**: SEO
   - **Task**: Optimize the client website for search engines.
   - **Output**: SEO-optimized client website.

## Output
- **Client Dashboard**: Client website with content and SEO optimization.
- **Analytics**: Client performance analytics.
