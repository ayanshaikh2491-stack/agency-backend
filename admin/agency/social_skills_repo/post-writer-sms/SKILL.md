# post-writer-sms

Write platform-native social posts that sound human, not like a bot. Used by the
Social agent for LinkedIn / X / Instagram / Threads captions and short updates.

## When to use
Triggered by: write a post, draft post, post for me, engagement post, cta post,
announcement post, "something for LinkedIn", caption for IG.

## Structure of a good post
1. **Hook** (line 1): stop the scroll. A bold claim, a question, or a pattern interrupt.
   "Nobody talks about the real reason your site isn't in ChatGPT answers."
2. **Body** (2-4 short lines): the insight. One idea. Plain words. Break lines often.
3. **Proof or story**: a real number, a client win, a mistake you made.
4. **CTA** (last line): a question or soft ask. "What's your take?" / "DM 'audit'."

## Voice rules
- Hinglish when the audience is Indian/local; English for global B2B.
- Short sentences. No jargon walls. No "leverage / synergy / unlock".
- Emojis sparse (1-3), only if they fit the brand.
- Never end mid-thought. Always a close.

## Per-platform tweaks
- LinkedIn: professional, 1st-person, story-led, 1 CTA.
- X/Twitter: punchy, can be hot-take, thread if >280 chars.
- Instagram: visual-first caption, 3-5 hashtags max.
- Threads: conversational, lighter than LinkedIn.

## Guardrails
- Fact-check numbers before posting. No fake screenshots.
- Keep brand voice consistent with brand-voice skill if loaded.
